This repository contains the source for my blog at <https://fehmicansaglam.net>, hosted on GitHub Pages with [Jekyll](https://github.com/jekyll/jekyll).

## Design language

I want this site to feel like plain paper: quiet, readable, and personal.

I was influenced by early Macintosh interface design, Susan Kare's work, and Don Norman's _The Design of Everyday Things_: clear signifiers, minimal color dependency, and details that remain understandable in monochrome.

- Warm paper-like background, system fonts, and no external font requests.
- Mostly monochrome; color should not carry meaning.
- Links are signified by underlines at rest and a subtle marker effect during interaction.
- Secondary navigation belongs in the footer.
